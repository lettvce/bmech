What this is

Every shape above is generated by the exact same Python code that ships in the Blender extension this project is built on — running unmodified in your browser via Pyodide, not a separate reimplementation. Nothing is uploaded anywhere; the mesh is built and the STL is written entirely on your machine.

  • Two more types (Wall Cubby, Cable Clip) need actual Blender/bmesh under the hood, so they aren't part of this browser demo yet.
  • This is free during testing. If it turns into a paid product later, existing free downloads aren't retroactively affected.
