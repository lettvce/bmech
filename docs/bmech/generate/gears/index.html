What this is

The exact same Python that ships in the bmech Blender extension runs unmodified in your browser via Pyodide, not a separate reimplementation. Nothing about the shape or your chosen dimensions is uploaded anywhere — the mesh is built and the STL is written entirely on your machine.

  • Every tooth profile is a genuine involute curve, built with the same geo_helpers Loop/Mesh DSL as every other live generator on this site — no BOOLEAN modifier, no EXACT-solver cleanup pass.
  • Planetary Set and Helical Planetary Set each build THREE kinds of part (a ring, a sun, and however many planets you ask for) — correctly phased so the teeth actually mesh — and merge them into one downloadable STL, positioned the same way the Blender operator lays them out.
  • Cluster Gear stacks two different-sized gears on one shared axle as a single printable piece — the top gear's OD has to fit inside the bottom gear's dedendum, flagged live if it doesn't.
  • This is free during testing. If it turns into a paid product later, existing free downloads aren't retroactively affected.
