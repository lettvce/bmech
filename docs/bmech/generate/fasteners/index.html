What this is

The exact same Python that ships in the bmech Blender extension runs unmodified in your browser via Pyodide, not a separate reimplementation. Nothing about the shape or your chosen dimensions is uploaded anywhere — the mesh is built and the STL is written entirely on your machine.

  • Every thread here is a single welded solid — no BOOLEAN modifier, no EXACT-solver cleanup pass. The Raw Thread tab outputs a bare thread for you to boolean into your own part by hand; every other tab is already a finished, printable piece.
  • Jar Set builds a matching Threaded Container + Threaded Lid pair in one shot, guaranteed to mate — both parts share one thread diameter/pitch/flank angle and a truncation resolved to whichever part needs the deeper cut.
  • This is free during testing. If it turns into a paid product later, existing free downloads aren't retroactively affected.
